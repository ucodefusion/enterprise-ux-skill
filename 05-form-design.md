# Forms and validation

## Structure
Use clear persistent labels, related field groups and logical keyboard order. Show optional/required status and examples. Use a wizard only when complexity or sequence warrants it.

## Data entry
Use autofill, dependent options, conditional fields, address autocomplete, format guidance, repeatable fields and copy previous values. Avoid unnecessary required fields.

## Validation
Validate near fields at appropriate times and on submit. Provide actionable messages, preserve values, focus error summary or first invalid field and validate on the server.

## Saving
Use sticky actions for long forms, draft/resume, unsaved-change protection, and Save and create another for repetitive work. Autosave only when semantics are clear; show saved/pending/error status.

## High-impact submissions
Provide review of meaningful consequences, explicit confirmation when needed, duplicate-submit protection and accessible success feedback.
