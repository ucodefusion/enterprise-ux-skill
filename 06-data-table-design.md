# Data tables, views and search

## Table anatomy
Place title/count above toolbar; search, filters, sort, view/columns and export in toolbar; selection at start of rows; identifiers near left; quick row actions near relevant data or consistently at end.

## Large datasets
Use server pagination or accessible virtualisation, sticky headers, useful frozen columns, column resizing/reordering, grouping and compact/comfortable density. Preserve user view preferences.

## Bulk operations
Show toolbar when selected; distinguish page selection from all matching records; confirm high-impact scope; report partial failures and offer retry.

## Choose a view
Table for comparison; list for browsing; cards for visual summaries; Kanban for workflow; tree for hierarchy; timeline for history; calendar for scheduling; Gantt for dependencies; pivot for analysis.

## Search and discovery
Global and local search, fuzzy matching where appropriate, search by ID, facets, grouped results, highlights, suggestions, recent and saved searches, previews. Cancel stale requests; show clear no-results state.

## Empty and filtered states
Distinguish no records from no matches; offer create/import for empty data and clear filters for no matches.
