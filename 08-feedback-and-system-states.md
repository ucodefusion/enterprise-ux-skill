# Feedback, system states and assistance

## State coverage
Design initial loading, refresh, empty, no results, success, validation error, network failure, offline, permission denied, session expiry, missing record, conflict, partial success and maintenance.

## Feedback placement
Inline for field errors; contextual banner for persistent page issues; toast for brief non-critical confirmation; modal only for necessary interruption. Announce important updates accessibly.

## Long operations
Show progress when measurable, otherwise indeterminate status; allow cancellation when safe, prevent duplicate submissions and retain results or failure details.

## Recovery
Preserve drafts and inputs; provide retry, undo or clear recovery path. Do not claim success until confirmed; label optimistic or pending changes.

## Onboarding and help
Use contextual help, examples, first-use guidance, optional onboarding checklist, help links and shortcut reference. Never make experienced users repeat tutorials.

## Intelligent UX
Suggest relevant next actions, prioritise exceptions, offer AI-assisted search/data entry with review and user control; do not silently commit high-impact AI actions.
