# Responsive layout and device ergonomics

## Desktop
Use persistent navigation, contextual panels and dense readable tables where helpful. Collapse or resize panels when space is constrained.

## Tablet
Prioritise content and primary actions; adapt sidebar to collapsible navigation; use drawers or stacked detail panels.

## Mobile
Use bottom navigation for a small set of main destinations, accessible menu for others, bottom sheets for contextual options and sticky primary actions where appropriate. Respect safe areas and keyboard.

## Responsive behaviour
Reflow content rather than shrinking text; avoid horizontal scrolling except for genuinely two-dimensional content; provide accessible table alternatives where useful.

## Sticky elements
Keep only useful headers, table headings or action footers sticky. Verify they do not obscure content, focused controls or error messages at zoom and small heights.
